20  Command Line (kis)

패키지를 설치하면 kis 터미널 명령이 함께 설치됩니다. 파이썬 코드를 쓰지 않고도 조회·주문할 수 있습니다. 조회·주문 명령은 같은 공개 API 를 호출하는 얇은 래퍼이고, kis config 는 자격증명 저장소를 다루는 대화형 명령 그룹입니다(병합·편집 흐름을 자체적으로 처리합니다).

자격증명은 --profile(계좌 종류), 환경(실전/모의)은 --environment 로 정합니다 – 서로 다른 두 축입니다. 프로필은 환경변수나 설정 파일에서 읽습니다. --profile 을 생략하면 기본 프로필 (KIS_DEFAULT_PROFILE 환경변수 > credentials.json 의 default_profile 마커 > 해석된 환경 블록에서 먼저 나오는 프로필, 그 블록에 이름이 없으면 다른 환경의 이름도 확인), --environment 를 생략하면 기본 환경(KIS_DEFAULT_ENVIRONMENT > default_environment 마커 > 모의 paper)을 씁니다. 모의가 기본이어도, 주문은 --execute 전까지 전송되지 않아 안전합니다.

kis --profile general --environment paper account balance # 종합위탁, 모의
kis --profile general --environment real  account balance # 종합위탁, 실전

프로필별 변수 접두어·설정 파일 위치(Linux·macOS·Windows 공통)는 자격증명과 프로필 을 참고하세요.

20.1 설정 (자격증명 저장)

kis config 는 자격증명을 다루는 명령 묶음입니다. 아무 하위명령 없이 실행하면 대화형 저장(setup)이 시작돼, 계좌 종류별로 실전·모의 앱키를 차례로 묻습니다(없는 환경은 Enter 로 건너뜀). 앱키·앱시크릿은 화면에 보이지 않게 입력받습니다(파이썬 코드 없이).

kis config                                  # 대화형으로 자격증명 저장(= kis config setup)
kis config setup --profile general          # 프로필 이름을 미리 주고 나머지만 프롬프트
kis config setup --set-default              # 저장 후 기본 프로필로 지정
kis config show                             # 저장된 설정을 마스킹해 보기
kis config list                             # 저장된 프로필 이름을 real/paper 환경별로 보기(시크릿 비노출)
kis config set general.paper.app_key        # 한 필드 수정(값 없이 주면 프롬프트)
kis config set general.real.account 12345678-01  # 비밀 아닌 account 만 값을 바로 줄 수 있음
kis config default profile general          # 기본 프로필 지정
kis config default environment real         # 기본 환경 지정 (env alias 가능)
kis config hts-id your_hts_id               # HTS 로그인 아이디 저장(조건검색·관심종목용)
kis config mcp                              # Claude Desktop 에 붙여넣을 MCP 설정 블록 출력
kis config migrate                          # 이전 형식 credentials.json 을 두 축 형식으로 변환
kis config migrate --yes                    # 비대화형: 기본 병합을 자동 승인(이름 충돌이면 거부)

kis config set <프로필>.<환경>.<필드> 로 한 슬롯의 한 값을 고칩니다. 수정 가능한 필드는 app_key· app_secret·account·account_password 이며, 명령줄에 값을 직접 줄 수 있는 건 비밀이 아닌 account 뿐이고 나머지(앱키·앱시크릿·계좌비밀번호)는 셸 기록에 남지 않도록 숨김 프롬프트로만 받습니다.

kis config migrate 는 기본적으로 병합 전에 확인을 묻습니다. --yes 를 주면 비대화형으로 기본 병합을 자동 승인하되, 이름 충돌로 프로필을 새로 지어야 하는 경우에는 덮어쓰지 않고 거부합니다.

실전(real) 슬롯은 저장 전 한 번 더 확인하고, 같은 자리가 이미 있으면 덮어쓸지 묻습니다. 다른 저장 방법(환경변수·파이썬 코드)과 자세한 내용은 자격증명과 프로필을 참고하세요.

20.2 조회

kis stock quote 005930                 # 현재가
kis stock quote AAPL --region overseas # 해외(거래소 자동)
kis stock bars 005930 --interval 1d --start 20240101
kis stock bars AAPL --region overseas --interval 1d --start 20240101  # 해외주식 기간봉
kis index quote SPX                                                  # S&P500 현재가(기본 해외)
kis index quote FX@KRW --kind fx                                    # 원/달러 환율 현재가
kis index bars FX@KRW --kind fx --interval 1d --start 20240101        # 원/달러 환율(기본 해외)
kis index bars SPX --interval 1d --start 20240101                     # 해외지수(S&P500 등)
kis index bars 0001 --region domestic --interval 1d --start 20240101  # 국내 지수(코스피)
kis stock book 005930                  # 호가
kis stock trades 005930                # 최근 체결
kis stock status 005930                # 거래정지·관리종목 등 상태
kis stock investors 005930             # 종목 투자자 수급(개인·외국인·기관 순매수, 일자별)
kis search 삼성전자 --market KOSPI
kis ranking change --direction gainers # 상승률 상위
kis ranking volume                     # 거래대금(기본)·거래량 등 상위
kis ranking market-cap                 # 시가총액 상위
kis market investors --market KOSPI    # 시장 전체 투자자 수급(외국인·개인·기관)
kis market net-buy --investor foreign  # 투자자별 순매수 상위 종목
kis account balance                    # 국내 잔고
kis account positions --region overseas --market US
kis account buyable 069500             # 종목 매수가능 여력(주문가능현금·매수가능수량)

kis account buyable <종목> 는 그 종목을 얼마나 살 수 있는지를 돌려줍니다 – 주문가능현금 (orderable_cash)과 현금 기준(cash_buyable_quantity)·미수 포함 최대(max_buyable_quantity) 매수가능 수량·금액. --limit-price 를 주면 그 지정가 기준, 없으면 시장가 기준입니다. 주식(위탁·연금·ISA) 계좌 전용입니다.

kis market 는 시장 전체 투자자 수급입니다 – investors 는 KOSPI/KOSDAQ 시장의 외국인·개인·기관 순매수, net-buy 는 투자자별 순매수 상위 종목(--basis 수량/대금, --side 매수/매도, --investor 전체/외국인/기관/기타; 생략 시 라이브러리 기본). 종목 단위 수급은 kis stock investors <코드> 입니다.

--exchange 값은 하위 명령에 따라 다릅니다. 주문 명령은 KRX/NXT/SOR, 시세 조회 명령은 KRX/NXT/UN을 쓰며, 해외 거래소 코드는 정해진 목록 없이 그대로 입력합니다.

아무 옵션 없이 쓰면 결과가 눈으로 보기 좋은 표로 나옵니다. 이 출력을 다른 프로그램이나 스크립트에서 자동으로 읽어(파싱해) 쓰려면 --format json 을 붙여 JSON 으로 받습니다(결과가 여러 행이면 한 줄에 한 건씩 주는 --format jsonl 도 있습니다). 벤더 원본 필드까지 함께 받으려면 --include-raw 를 더합니다(각 항목에 _raw 로 KIS 응답 원본이 붙습니다).

kis stock quote 005930 --format json
kis stock quote 005930 --format json --include-raw # KIS 원본 필드 포함

일별 주문·체결 내역(기간)은 kis account fills 로 조회합니다. 기본은 국내주식(--asset stock), 장내채권은 --asset bond. --start/--end(YYYYMMDD) 로 기간을 주고, --side(all/buy/sell)·--symbol(주식 6자리 / 채권 ISIN)·--unfilled-only 로 좁힙니다. 주식 체결내역은 기본으로 최근·과거 조회를 모두 수행하므로, 오래된 기간에도 별도 플래그가 필요하지 않습니다. --older-than-three-months 를 명시하면 기존처럼 과거 조회만 합니다. 체결내역(fills)은 국내주식은 실전·모의 모두, 장내채권은 실전 계좌 전용입니다(모의투자 미지원). 미체결(정정·취소 대상)만 보려면 kis account orders 를 씁니다 – 국내주식·장내채권 모두 실전 계좌 전용입니다(정정취소가능주문조회는 모의투자 미지원).

kis account fills --start 20240101 --end 20240131                              # 최근·과거 자동 조회
kis account fills --start 20240101 --end 20240131 --symbol 005930 --side buy   # 종목·매수만
kis account fills --start 20230101 --end 20230331 --older-than-three-months    # 3개월 이전 체결내역
kis account fills --asset bond --start 20240101 --end 20240131                 # 장내채권 체결내역
kis account fills --asset bond --start 20240101 --end 20240131 --unfilled-only # 미체결만

국내주식의 기본 결과는 결합한 orders 와 출처별 recent·historical 내역입니다. 기존 단일 조회의 최상위 합계 필드를 읽던 스크립트는 출처별 요약을 확인해야 합니다. 평균 매입가격·추정 비용을 임의로 합친 값은 제공하지 않습니다. 한쪽 조회 실패나 식별 정보가 갖춰진 동일 주문의 서로 다른 관측이 발견되면 결합 오류를 반환하며, 조회 기간·보관 범위를 넘어선 내역의 존재까지 보장하지는 않습니다.

예약주문(정규장이 열리기 전에 미리 걸어두는 예약) 목록은 kis account reserved --start/--end 로 조회합니다(YYYYMMDD). 국내 조회는 --process 로 all/processed/unprocessed 를 골라 좁히며 실전 계좌 전용입니다(모의투자 미지원). 해외 예약주문은 --region overseas 로 조회하고(미국+아시아 합산) --process 는 지원하지 않습니다. 해외 조회 기간은 종료일과 시작일의 차이가 6일 이하여야 합니다 (예: 1월 1일~7일).

kis account reserved --start 20240101 --end 20240131                       # 국내 예약주문 목록
kis account reserved --start 20240101 --end 20240131 --process unprocessed # 미처리분만
kis account reserved --region overseas --start 20240101 --end 20240107     # 해외 예약주문 목록

기간별 실현손익은 kis account profits --start/--end 로 봅니다. --symbol 로 종목을 좁히는 건 국내·해외 공통이고, 국내는 --by symbol(종목별 실현손익, 기본)/--by day(일별 매매손익)· --sort recent|oldest, 해외주식은 --region overseas 로 기간손익을 보며 --currency· --won-basis(원화 기준) 를 씁니다. 실전 계좌 전용입니다(모의투자 미지원).

kis account profits --start 20240101 --end 20240131                  # 국내 종목별 실현손익
kis account profits --start 20240101 --end 20240131 --by day         # 국내 일별 매매손익
kis account profits --region overseas --start 20240101 --end 20240131 # 해외주식 기간손익

거래·입출금내역(매매·결제·수수료)은 kis account transactions --start/--end 로 조회합니다. 해외주식은 --region overseas(--symbol·--side all|buy|sell 로 좁힘), 해외선물옵션은 08 프로필로 실행하면 같은 명령이 해외파생 입출금내역을 조회합니다. 실전 계좌 전용입니다.

kis account transactions --region overseas --start 20240101 --end 20240131 # 해외 거래·입출금내역

선물옵션 계좌 조회

kis account 명령은 프로필이 연 계좌 종류(주식 / 국내선물옵션 / 해외선물옵션)에 맞게 동작합니다 – 선물옵션 프로필로 실행하면 같은 명령이 선물옵션 계좌를 조회합니다(계좌 종류는 프로필의 상품코드로 정해지며, 각 분기가 안 쓰는 플래그를 주면 거부합니다).

  • balance – 국내파생은 잔고(보유+예수금·증거금·손익 요약), 해외파생은 예수금현황.
  • positions – 해외파생 미결제내역(국내파생은 balance 에 포함).
  • orders – 국내파생 미체결(--date 로 주문일자), 해외파생은 당일 주문(기간 --start/--end 주면 일별).
  • fills – 국내파생 기준일체결내역(--date 필수), 해외파생 일별체결(--start/--end).
  • profits – 해외파생 기간손익(--start/--end).
  • transactions – 해외파생 기간 입출금내역(--start/--end).

계좌 종류별 추가 조회:

  • deposit – 예수금현황(국내·해외 선물옵션; 해외파생은 --currency/--date).
  • margin – 증거금상세(국내파생 야간증거금 / 해외파생 --currency/--date).
  • valuation – 국내파생 평가손익내역.
  • settlement – 국내파생 정산손익(--date) / 해외주식 정산잔고(--region overseas --date).
  • commissions – 국내파생 기간약정수수료(--start/--end).
  • present – 해외주식 체결기준현재잔고.
  • foreign-margin – 해외주식 외화증거금.

모두 조회 전용입니다(대부분 실전 계좌 전용 – 모의 지원 여부는 라이브러리가 정합니다).

kis --profile derivatives account balance                                     # 국내선물옵션 잔고(03 프로필)
kis --profile derivatives account fills --date 20240102                       # 국내파생 기준일 체결내역
kis --profile overseas_derivatives account profits --start 20240101 --end 20240131 # 해외파생 기간손익(08)
kis --profile overseas_derivatives account margin --currency USD                   # 해외파생 증거금상세

20.3 주문 — 기본은 dry-run

주문 명령은 --execute 가 없으면 전송하지 않고 주문 티켓만 되읽어 보여줍니다.

kis order buy 005930 10 --limit-price 70000                                 # dry-run (전송 안 됨)
kis --environment paper order buy 005930 10 --limit-price 70000 --execute paper # 모의 전송(확인 후)

국내 현금주문은 --division 으로 KRX 주문구분을 고릅니다.

--division 주문구분 --limit-price 비고
conditional_limit 조건부지정가 필수
immediate_limit 최유리지정가 —
priority_limit 최우선지정가 —
midpoint 중간가 — 호가 중간값, 전 거래소, IOC/FOK
pre_market_close 장전 시간외 종가 — KRX 전용
post_market_close 장후 시간외 종가 — KRX 전용
after_market_limit 애프터마켓 지정가 필수 --exchange KRX, 16:00~20:00
after_market_immediate_limit 애프터마켓 최유리 — --exchange KRX
after_market_priority_limit 애프터마켓 최우선 — --exchange KRX, day 전용
gtp_limit NXT GTP 지정가 필수 --exchange NXT, day 전용
gtp_immediate_limit NXT GTP 최유리 — --exchange NXT, day 전용
gtp_priority_limit NXT GTP 최우선 — --exchange NXT, day 전용

--limit-price 칸이 — 인 구분은 시장이 가격을 정하므로 지정가를 주지 않습니다. 해외 (--region overseas)엔 미지원입니다.

kis --profile general --environment real order buy 005930 10 --division immediate_limit --execute real --yes --confirm-account 7801

국내 주식 스톱지정가는 --stop-price 로 트리거(조건가격)를 줍니다. 시장이 그 값에 닿으면 그때 --limit-price 가격으로 지정가가 접수됩니다. --stop-price 는 --limit-price 가 반드시 필요하고 (스톱시장가는 없습니다), --division 과 함께 쓸 수 없습니다. KRX 전용이라 정규장(09:00~15:30)에만 나갑니다 – 장 시간 밖의 접수는 서버가 거부합니다.

kis order buy 005930 10 --limit-price 70000 --stop-price 69000 # dry-run (전송 안 됨)

예약주문(정규장이 열리기 전에 미리 걸어두는 예약)은 kis order buy/kis order sell 에 --reserve 를 주어 냅니다 – 국내 주식은 다음 영업일 동시호가에 집행되며 실전 전용이고 --end-date YYYYMMDD 로 예약 유효 종료일을 지정합니다. 취소는 kis order cancel-reserved <순번> 이며, 순번은 예약 발주 결과나 kis account reserved 목록의 reserved_order_id 입니다. 정정은 kis order modify-reserved <순번> 이며, 브로커 규격상 --symbol/--side/--quantity 로 종목·방향·수량을 전체 재지정합니다 – --limit-price 를 생략하면 기존 단가 유지가 아니라 시장가로 바뀌니 주의하세요(--end-date/ --order-date 도 지정 가능). 예약 신규·정정은 설정한 RiskLimits 의 수량·확정 가격 기준 한도를 검사합니다. 참조 가격이 필요한 한도를 조회 없이 검사할 수 없으면 거부하며, 취소는 계속 사용할 수 있습니다. 정정 후 예약 순번이 재배정될 수 있어(응답은 새 순번을 주지 않음) 이어서 정정·취소하려면 kis account reserved 로 순번을 재확인하세요 – 영수증에도 같은 안내가 실립니다. 다른 주문과 같은 dry-run/--execute 안전장치를 씁니다.

해외 예약주문은 --region overseas 로 냅니다 – 국내와 달리 지정가 전용(--limit-price 필수), --end-date 미지원, 모의(paper) 허용입니다. --currency(HKD/CNY/USD)는 홍콩 예약 전용이고 미지정 시 홍콩은 HKD 입니다. 목록은 kis account reserved --region overseas(미국+아시아 합산), 취소는 kis order cancel-reserved --region overseas --receipt-date YYYYMMDD 로 미국 예약만 됩니다 – 아시아(일/중/홍/베) 예약 취소는 발주 리포트의 client_order_id 로 kis order cancel 을 사용합니다. 이 CLI는 해외 예약 정정(modify)을 지원하지 않습니다.

kis order buy 005930 10 --limit-price 70000 --reserve --end-date 20240131                          # 국내 예약매수(dry-run)
kis order cancel-reserved SEQ7 --order-date 20240131                                               # 국내 예약 취소(dry-run)
kis order modify-reserved SEQ7 --symbol 005930 --side buy --quantity 10 --limit-price 71000        # 국내 예약 정정(dry-run)
kis order buy 00700 100 --region overseas --reserve --limit-price 350 --exchange HKS --currency HKD # 해외(홍콩) 예약매수(dry-run)
kis account reserved --region overseas --start 20240101 --end 20240107                             # 해외 예약주문 목록
kis order cancel-reserved US123 --region overseas --receipt-date 20240131                          # 해외(미국) 예약 취소(dry-run)

국내 주식 TWAP 분할은 kis order twap 으로 냅니다 – 총 수량을 --over(총 소요시간, 예 30m/ 1h/1h30m) 동안 --slices(분할 횟수)로 나눠 시장가로 여러 번 발주합니다. --start HHMMSS(KST, 생략 시 지금부터, 과거는 거부)로 시작 시각을 정하며, 모든 슬라이스가 KRX 정규장(09:00~15:30 KST) 안이어야 합니다. 다른 주문과 달리 실행 동안 호출을 블로킹하고, 기본은 스케줄만 보여주는 dry-run, --execute 로 실제 집행합니다. 슬라이스별 거부·시간초과와 미달 수량을 결과에 기록합니다. 결과가 completed 이면 종료 코드 0, incomplete 이면 5, unknown 이면 7, interrupted 이면 130입니다. 중단과 결과 불명 주문이 함께 있으면 중단 결과와 미확인 주문 ID를 모두 보존하므로, 종료 코드만 보지 말고 결과의 미확인 ID도 확인하세요.

kis order twap 005930 --side buy --quantity 100 --over 30m --slices 3 # dry-run: 스케줄 미리보기
kis order twap 005930 --side buy --quantity 100 --over 30m --slices 3 \
  --start 130000 --execute paper --yes                                # 13:00 시작, 실제 집행

미국주식 algo 분할주문(서버가 쪼개 집행)은 해외 매수/매도에 --algo twap/vwap 를 줍니다 – 미국·실전 전용입니다. 주문유형별 거래단위는 KIS 미국시장 안내와 브로커의 주문 조건을 확인하세요. --algo-start/--algo-end(KST HHMMSS, 같은 날·시작<종료, 자정 넘김 불가)로 시간창을 주거나 생략하면 정규장 종료까지 집행합니다(미국 정규장은 KST 로 자정을 넘어 한 창이 세션 전체를 덮지 못하니 전체 집행은 시간창 생략). 자세한 규칙은 주문 참조.

kis order buy AAPL 10 --region overseas --limit-price 150 --algo twap --execute real --yes # 전체 세션(시간창 생략)
kis order buy AAPL 10 --region overseas --limit-price 150 \
  --algo twap --algo-start 223000 --algo-end 235959 --execute real --yes                  # KST 같은 날 구간

실제 전송하려면 --execute 값이 세션 환경(--environment 로 고른 실전/모의)과 같아야 합니다. 대화형에서는 확인을 받습니다(모의는 y/N, 실전은 계좌 마지막 4자리 입력). 스크립트(비대화형)에서는 --yes 가 필요하고, 실전은 --confirm-account 로 계좌 마지막 4자리를 한 번 더 맞춰야 합니다.

kis --profile general --environment real order buy 005930 10 --limit-price 70000 \
    --execute real --yes --confirm-account 7801

정정·취소·확인은 client_order_id 로 지목합니다. 결과가 불명(타임아웃)이면 재전송하지 말고 reconcile 로 저장된 상태를 확인하세요. 저장된 유효한 증권사 주문번호가 없으면 경제 조건만으로 최초 연결하지 않고 None 과 처리 중 기록을 유지합니다. 번호가 있는 주문은 지원 자산군에서 상태를 갱신합니다. 불명 상태는 HTS/MTS나 해당 계좌의 주문·체결 조회로 수동 확인하고, 결과가 없다는 이유로 재전송하지 마세요. 해외선물옵션 주문의 reconcile 은 지원하지 않습니다.

kis order modify <client_order_id> --limit-price 70500 --execute real --yes --confirm-account 7801
kis order cancel <client_order_id> --execute real --yes --confirm-account 7801
kis order reconcile <client_order_id>
중요

CLI 의 --yes 는 오타 방어용입니다. 에이전트(Claude 등)가 계좌를 몰 때는 CLI 가 아니라 파이썬 API 를 안전커널 규율대로 쓰는 것이 맞습니다 – 주문의 안전장치 참고.

20.4 종료 코드

스크립트에서 결과를 분기할 수 있게 종료 코드를 구분합니다.

코드 뜻
0 성공(TWAP은 completed)
2 인자 형식 오류
3 로컬 구성·자격증명 문제
4 도메인 검증·리스크 거부(전송 안 됨)
5 전송 실패 또는 TWAP 미달(incomplete)
6 브로커 거부
7 주문 결과 불확실(저장 상태 및 계좌 조회·수동 확인 필요), TWAP unknown 포함
130 사용자 중단(Ctrl-C), TWAP interrupted 포함

이 종료 코드는 KIS 가 정한 게 아니라 이 CLI 가 스크립트용으로 매긴 규약입니다. 2 는 argparse 표준(인자 오류), 130 은 유닉스 관례(Ctrl-C 중단 = 128 + 시그널 2)를 따른 것이고, 3~7 은 주문 결과를 스크립트가 구분할 수 있게 이 도구가 정했습니다.
